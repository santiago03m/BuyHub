# BuyHub 🛒🔎

Buscador y comparador de productos por referencia comercial exacta para comercios en Colombia. 

El objetivo de **BuyHub** es permitir búsquedas precisas (ej. `[Marca] + [Referencia]`), separando el producto principal de repuestos, accesorios o resultados ambiguos en múltiples tiendas.

## 🛠️ Metodología de Trabajo
Gestionamos el desarrollo de forma iterativa mediante **GitHub Projects** e **Issues** estandarizados:
- **Spikes (`SPIKE-XXX`):** Investigaciones técnicas acotadas en tiempo para validar fuentes y viabilidad antes de programar.
- **Historias de Usuario (`US-XXX`):** Funcionalidades verificables centradas en el usuario final.
